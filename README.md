# 先开始｜家庭晚间习惯助手 MVP

面向小学低年级家庭的移动端 Web MVP。家长与孩子共同商定今晚任务、休息方式和第一小步；孩子离屏执行，卡住时可以求助或暂停；完成后家长与孩子共同获得家庭能量，并在每周复盘中只调整一个变量。

## 已实现

- 监护人授权与化名档案
- 家长主动录入或粘贴今晚事项
- 最多三项的家庭共同计划
- 休息选择与孩子第一小步
- 离屏安静模式与卡住求助
- 完成、部分完成、合理暂停三种结果
- 双方共同贡献的家庭能量
- 每周启动、提醒、冲突复盘
- 风险提示与学校／医疗转介
- D1 云端最小记录、本地偏好、导出与删除
- 提示音、减少动态效果与移动端无障碍交互

## 开发
