# 先开始｜家庭晚间习惯助手 MVP

面向小学生家庭的低屏幕移动端 Web MVP。家长与孩子共同商定今晚的事项、时间和家庭能量，通过双人确认启动；孩子离屏执行，晚间合作与共同期待实现记录会留在家庭日历。

产品目标是减少反复催促和亲子冲突，帮助家庭形成“共同计划—自主启动—柔和过渡—完成收尾”的稳定节奏，不承诺提高成绩，也不用于诊断注意力、心理或学习障碍。

## 已实现

- 监护人与孩子化名档案，不收集年级、学校和精确位置
- 自定义今晚可用时间与不限三项的共同日程
- 约 40 类原创活动图标及自定义图标入口
- 每项任务独立设置时间、主观难度和 1–5 点能量
- 家长与孩子分别点亮确认，形成轻量家庭约定
- 离屏执行、阶段完成提醒、求助与中途调整计划
- 家庭能量与共同期待；实际一起实现并记录后，下一份期待从 0 开始
- 每日合作与共同期待日历、每周复盘
- 风险提示、数据导出与删除、减少动态效果
- 本地存储与 Cloudflare D1 最小化状态同步

## 开发

```bash
npm install
npm run dev
npm test
```

界面参考图和设计依据位于 `outputs/ui-reference/`，不参与部署。

## 数据与隐私说明

当前 MVP 会在浏览器本地保存家庭状态，并通过匿名 `familyId` 同步到 Cloudflare D1。它尚未实现适合公开生产环境的监护人账号鉴权，因此公开试用前应选择“仅本机保存”，或补充正式的监护人登录与访问控制。
